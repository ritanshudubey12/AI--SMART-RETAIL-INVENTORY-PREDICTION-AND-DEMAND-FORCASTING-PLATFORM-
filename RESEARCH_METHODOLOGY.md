# Research Methodology

RQ1: Can ML improve forecasting over selected baselines?
RQ2: Which features contribute most?
RQ3: How do XGBoost, LightGBM, statistical models and LSTM compare?
RQ4: Does better forecasting improve inventory performance?
RQ5: Can explainable AI improve interpretation?

Use M5 as a benchmark without redistributing its files.

Experiments:
1. Baseline vs ML
2. Feature ablation
3. ML vs LSTM
4. Forecast-driven replenishment vs baseline
5. Explainability

Metrics:
MAE, RMSE, WAPE, Bias, stock-out rate, service level, average inventory, turnover, holding-cost proxy.
