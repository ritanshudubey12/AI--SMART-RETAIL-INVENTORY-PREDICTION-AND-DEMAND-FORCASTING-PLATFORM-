# Claude Build Pack

Use `MASTER_PROMPT_FOR_CLAUDE.md` as the main prompt in Claude Code.

This pack is a specification and starter build guide, not a claim that the complete production application has already been generated. Claude Code should create the actual repository implementation from the master prompt.

Recommended order:
1. Open your project repository in Claude Code.
2. Give Claude the master prompt.
3. Let it inspect the repository.
4. Implement phase-by-phase.
5. Run tests after every phase.
